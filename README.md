# AI商机

持续发现需求信息、汇集客户内外部资料的平台。允许需求模糊，不强制采购金额或商机分级；人员核实，AI 辅助整理及后续客户分析。

当前处于设计基线阶段，尚无可运行服务；文档中的功能为开发计划，不代表已经实现。

## 技术方向

React + TypeScript；Python + FastAPI；Celery + Redis；PostgreSQL；SSE；原文与附件独立存储。搜索服务、采集工具、模型和通知渠道通过适配器接入。具体版本在工程初始化时验证并锁定。

## Git 工作方式

使用现有本地 Git 仓库，功能分支为 `codex/<topic>`。每个可审阅里程碑提交一次，变更说明包含验证及未完成项。远程建议使用私有仓库；托管平台和归属确定后再创建、推送。密钥、账号会话、客户资料和采集内容不得提交。
