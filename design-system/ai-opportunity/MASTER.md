# AI_Business_Opportunities 设计方向 v0.2

用户修订：年轻化、二次元、跳跃色彩、原创 SVG 角色及头像。以下新方向取代 v0.1 的沉稳深青色方案，保留可读性和交互规则。

## 新方向

- 产品：给业务人员的信息探索基地
- 性格：机敏、活泼、有探索欲
- 场景：都市动漫中的情报站与任务终端
- 重点：原创蜘蛛侦察员 SVG、任务卡和有节奏的撞色状态
- 标识：蜘蛛拾取信息后，卡片沿任务轨迹进入信息库

推荐方向：都市动漫情报站。中性底色，酸橙黄用于主动作，电光青用于执行轨迹，帆布灰用于辅助面板；错误仍使用专门的语义样式。后台内容区保持易读，大屏可采用更强对比。漫画切角和贴纸仅用于模块标题或角色卡，正文、表格不倾斜。

SVG 角色可出现在侧栏、空状态和执行说明；人员头像与机器人头像有明确标注。授权失败保留清晰文字和操作入口，不仅靠角色表情。素材原创或具备明确许可，不直接搬用游戏角色。

参考方向：
- https://zenless.hoyoverse.com/main ：都市潮流、角色与功能界面结合
- https://persona.atlus.com/p5r/index.html ：漫画切角、强对比，只借鉴局部语言
- https://www.arknights.global/ ：情报终端与任务面板的秩序感

以上是视觉参考和设计提案，不表示已制作原型。

## v0.1 历史基线（视觉方向已被上文取代）

# AI商机设计方向 v0.1

状态：用户已确认年轻化二次元方向，已制作独立交互样稿；业务 UI 尚未实现。

## 五行方向

- 产品：为业务人员持续发现需求信息，并汇集客户内外部证据。
- 性格：沉稳、精确、持续工作。
- 场景：信息观察室与业务处理台；操作后台浅色，展示大屏石墨深色。
- 重点：信息详情中的证据脉络；大屏中央真实事件驱动的线框蜘蛛。
- 标识：贯穿搜索、采集、清洗、归集和通知的细线流程，阶段状态与时间对应。

## 设计依据与选择

UI/UX Pro Max 已检索 enterprise monitoring operations dashboard 和 data dense dashboard。采用后者 Data-Dense Dashboard 的信息密度、筛选和行状态建议，以及可访问性规则。输出中的营销落地页、玻璃效果和外部字体依赖不适合本产品，不采用；最终配色为产品设计判断，不声称来自完整匹配的自动模板。

unslop 当前无既有 UI 可审计；按新建产品建立方向。其方法由 Damir Sokolovsky 创建，参考 https://heydamir.design/unslop ，CC BY 4.0。遵循先间距再颜色、图标、文案、排版、布局、细节、视觉、动效的检查顺序。

## 视觉规则

- 后台：中性浅灰背景、白色内容区、深灰文字；深青色为主操作候选强调色。大屏：石墨背景，任务和信息为视觉焦点。
- 颜色以语义 token 管理；正常、等待、异常均有文字/图形辅助，不只靠颜色。实际 token 在原型阶段测量文字对比度至少 4.5:1。
- 4px 间距基线；桌面侧栏约 240px；页面间距 24–32px。组件常规圆角 8px，不将所有元素做成胶囊。
- 中文使用系统中文字体回退，不依赖远程字体服务；正文以 16px 为基线，表格可采用 14px；数字等宽对齐。
- 单一线性图标集；无 emoji 导航、装饰性渐变、发光边框、彩色阴影。
- 后台以表格、详情、时间线为主，不把所有内容做成等宽卡片。
- 动画仅服务状态理解。持续蜘蛛动画是用户明确需求，保留，但支持暂停和 reduced-motion；不让无任务动画伪装为成功采集。
- 图表标明时间范围、数量单位、更新时间；后台保存 UTC，展示默认 Asia/Shanghai。

## 响应式与无障碍

后台以桌面业务操作为主，窄屏折叠侧栏和次要列，不缩小整个桌面。大屏优先 1920×1080，其他尺寸重排。键盘焦点明显，交互有文本名称，表单可见标签，图表有文本摘要。自动滚动可暂停，减少动态效果时显示静态任务快照。

浏览器基线暂定当前稳定 Chrome/Edge，兼顾 Firefox/Safari 的核心操作；采用未广泛支持的特性时必须提供降级。实施时按 modern-web-guidance 重新验证。


## 2026-11-14 参考补充

用户确认酸橙黄、电光青、帆布灰，继续采用年轻化二次元方向。浏览器观察了用户提供的 11 秒视频：浅色信息卡与深色档案面板并置，多只蜘蛛及交错运动轨迹。采用多蜘蛛、节点与轨迹概念，轨迹设置淡出和数量上限。独立演示包含工作台/大屏切换、信息详情、运行/待命/断线和暂停动画；演示数据明确标识，未接真实后端。不进行本地 Git 提交或远程推送。


## 用户后续修订：单只大蜘蛛

采用单只大线框蜘蛛，八足关节清楚；放弃多小蜘蛛和密集轨迹。动作顺序：爬向信息、抓取摘要、送往右侧信息栏、条目归集。右侧档案/信息栏保留。原型明确为演示，正式版本由真实事件驱动。


## 最新修订：浅色原文搬运

用户否定黑底与纯动画节点。大屏改为浅帆布底色，酸橙黄、电光青、薄荷绿和珊瑚粉明显分区。主画面展示来源、标题和原文，单蜘蛛定位高亮片段，连续移动相同原文到右侧信息栏，落成带来源含义的待核实卡片。不能只搬泛化标题。当前仅演示数据。


## 最新方向：参考视频的档案终端

用户否定普通彩色卡片后台。当前方向改为纸灰来源档案、墨色归集表、细线和档案编号，参考 Twitter 视频而非营销式卡片。顶部必须为持续变化的真实图表，不能替换为大数字。交互样稿使用两条累计曲线：已采集按模拟流增长，已归集随蜘蛛落表更新。右侧使用语义表格：编号/来源、原文、状态。单只蜘蛛搬运同一段原文。保留暂停/待命/断线和演示标识。此条覆盖此前浅色彩色卡片建议。

当前预览为 business-terminal.html；旧 business-scout.html 保留作版本比较，均未接后端。后续生产实现必须使用持久化真实事件统计，不可保留模拟增长逻辑。


## 最新布局修订：左终端、右宽表

桌面采用左侧 1/3 黑色命令行采集终端（网址、时间、title/body 原文、执行日志），右侧 2/3 浅色归集表。单蜘蛛在同一水平轨道左右搬运，落表后返回。顶部保留动态双折线。底部阶段栏随任务循环联动：定位来源、读取原文、清洗归集、写入表格；人工核实不作为自动完成阶段。窄屏允许上下重排。当前预览 business-terminal-wide.html。

## 最新修订：简洁标题与深色信息库

本条覆盖前述冲突视觉约定。标题仅“AI商机智能体”，不加图标、英文品牌条或宣传语。加入全屏；生产大屏不放演示场景切换、暂停/继续动画按钮。原型保留小号“演示数据”说明，遵循系统减少动态效果设置。真正断线仍须如实显示最后更新时间，不能把演示开关与实际异常提示混同。

顶部三图：累计采集与归集折线、归集来源横向条形图、待处理任务曲线。浅灰纸色外框，左侧 1/3 黑色命令行原文区，右侧 2/3 深蓝黑色信息表。单只细线关节蜘蛛使用深色身体、青蓝紫变化的腿线、粉色关节点。脚落地交替步进；原文拉成彩条，向右搬运后写入同样原文，随后返回。表格包含来源、时间、原文、原始网址、联系方式；未获取的联系方式不编造。

参考研究：两段视频分别约 17 秒、11 秒，覆盖全时长逐秒抽帧。已读取 fredfokan/web-crawler 的手写源码、README、构建和页面模板；它是明确注明 inspired by rybinfx 的复刻，未确认原作者源码仓库。当前实现独立编写，未复制该仓库的完整蜘蛛代码。当前预览 business-crawler-refined.html；模拟数据未连接后端，重复样本只是动画演示，生产需去重。未新增 Git 提交或推送。

## 整体统一与分配接收表

当前预览 business-overview.html。用户认可图表与蜘蛛总体逻辑，要求消除乳白/黄灰/黑底拼接感。本版背景统一石墨灰阶：页面 #171a1e，面板 #1c2025，表头 #24292f，分隔 #353b43；文字 #e5e8ec / #a6afb9。图表采用相同面板底色及深色模式，青/粉/绿/金只承载图表或状态含义。来源终端与信息库共用同一表面色。保留原单蜘蛛与三图，不另起视觉方向。

底部新增“分配与接收”表：信息、负责人、分配时间、推送结果、接收状态、接收时间。发送成功与人员接收分开，人员接收必须来自显式确认，不能以 IM 返回成功替代。当前人员及回执是静态演示样本，没有发送真实消息；表格插入仅影响信息库，分配表独立。

## 2026-11-14 功能版视觉还原（覆盖前述历史冲突）

方向继续使用已确认的 business-overview 原型：信息观察室、机敏而克制、统一石墨表面；色彩集中于三组图表与搬运原文；单只细线关节蜘蛛是识别元素。禁止接后端时擅自替换已确认的图表类型。

- 大屏中文优先 PingFang SC / Microsoft YaHei，终端和元信息使用等宽字体；标题20–24px、模块标题14px、表格13px、辅助信息11–12px。
- 24px页面边距、16px模块间距、直角细边框；桌面三图1.5:1:1，左终端右信息库1:2；760px以下上下排列。
- 图表：青色累计采集结果、粉色累计去重归集；来源横条；金色待处理任务曲线。采集以搜索返回后创建的 ingest 任务计数，归集以唯一信息计数。来源当前按 provider，未实现业务来源分类时不伪造“招聘/需求/客户”标签。
- 趋势窗口30分钟，保留窗口前累计基数；积压以排队/重试入队与执行出队的持久化事件还原，按每分钟末状态，不含等待授权。
- 顶部仅名称、模式标记、收起的设置和全屏；连接信息移至页尾。分配表保留六列表头，未接功能明确空态。
- 无数据/低数据保持真实；不能复制原型模拟曲线冒充采集结果。验收使用运行版截图。

## 2026-11-15 本地视频覆盖规则

本轮以用户提供的 crawler.mp4 为视觉依据：产品是业务情报观察台；性格为机敏、精确；来源区是黑底阅读文档；视觉重点是被抓取的原文与细线蜘蛛；识别细节是前腿牵住文字条再送入右侧对应列。来源终端采用 #030303 黑底、灰白正文、蓝紫链接、衬线文档标题和分节细线，不再做字段卡片堆叠。单条信息用语义 HTML 组织成 Markdown 阅读样式，保留原句、上下文和真实时间，不虚构完整网页正文。

蜘蛛按视频重建为黑色窄矩形身体、蓝紫描边、粉色头部标记、珊瑚细线腿、薄荷绿关节；八足交替落地，上一落点连续返回下一字段。抓取序列为接近、框选、提起、携带、落地，前腿牵引线与字条相连。来源高亮保留；右侧仍是单行中性灰标签和省略号。图表、地图和认领表不随来源终端换风格。视频是外观参照，不表示已取得原作者源码；本轮为独立实现。
