# 0.1 实现与验证记录

## 已完成

- PostgreSQL 迁移：规则、任务、尝试记录、任务 Outbox、原文版本、信息条目、持久化事件。
- 任务仅携带 ID 入 Redis；数据库先提交，独立调度器再投递。未确认执行的消息每 30 秒重新投递，消费者通过锁和租约令牌防重复写入。
- Worker 有限重试、授权等待、超时租约回收；不同来源结果使用独立子任务。
- Tavily 搜索适配器和独立演示适配器；原文留存、正文/摘要区分、精确去重、邮箱与大陆手机号候选提取。
- 规则创建/启停/手动运行、任务查询/重试、证据详情、信息列表 API；管理员/脱敏展示令牌隔离。
- React 管理台与石墨灰大屏；图表读取数据库统计，SSE 重连加快照校正，新增信息触发蜘蛛搬运。首次打开不虚构历史动画。
- 分配与通知区域显示尚未接入，不用演示回执充当真实功能。

## 本轮验证

- 18 项后端测试通过：重复消息、租约回收/过期 Worker 隔离、重试上限、Redis 不可用时投递记录回滚、缺少密钥隔离、不同来源子任务隔离、权限、演示/真实分离、供应商正文/摘要映射。
- 前端 TypeScript 与 Vite 生产构建通过。
- 本机独立 PostgreSQL 17 / Redis 7.4 容器 + 原生 Python API、Celery Worker、调度器跑通完整演示链路。
- 实际停止本项目 Redis，API 仍接受任务并入库；恢复 Redis 后该任务成功完成。
- PostgreSQL 执行迁移并运行 Alembic check，无 schema 漂移。
- 前后端 Docker 镜像构建成功；数据库、Redis、API、Worker、调度器、Nginx 前端全部通过 Compose 启动。容器环境再次跑通完整演示链路，浏览器验证生产前端登录、统计与 SSE。
- 浏览器验证令牌登录、新建规则、执行一次、缺少密钥进入待配置、信息库、大屏统计。

## 尚未完成或验证

- 尚未配置真实 Tavily 密钥；没有声称真实搜索验收成功。
- 当前仅为本机回环地址部署；尚未进行公网域名、HTTPS、反向代理访问控制与生产环境验收。
- 未进行 24 小时持续运行、备份恢复、资源容量与多实例压力验收。
- 直接网页抓取、平台登录/扫码、账号管理、预算控制、CRM、AI 分析、人员分配及 IM 回执仍在后续里程碑。
- 当前列表仅前 50/100 条，API 支持 offset/limit；完整分页操作、规则内容编辑、用户角色管理、事件归档未完成。
- SSE 当前保留全部事件，无清理期；未来加入保留期时需增加游标过期后的快照重置协议。
