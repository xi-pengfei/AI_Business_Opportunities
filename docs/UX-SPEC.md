# 页面与交互规格 v0.1

## 导航和路由

| 区域 | 路由 | 页面目标 |
|---|---|---|
| 工作 | /overview | 查看总体推进情况、局部异常、最近成功时间 |
| 工作 | /information、/information/:id | 筛选信息，查看证据和 AI 理由，分配与核实 |
| 工作 | /customers、/customers/:id | 客户档案与内外部时间线，未接 CRM 也可使用 |
| 采集 | /rules、/rules/new、/rules/:id | 关键词/客户监测规则，草稿、试搜、启停 |
| 采集 | /sources、/accounts | 来源健康、账号授权、限速和恢复 |
| 运行 | /tasks、/tasks/:id | 阶段、尝试记录、错误原因及重试 |
| 运行 | /notifications | 发送、结果未知、人员确认等状态 |
| 设置 | /settings/providers、/settings/crm、/settings/display | API、预算、CRM 字段映射、展示范围 |
| 展示 | /display | 独立布局、只读、脱敏，不展示后台侧栏 |

详情应可直接链接。列表筛选、分页和排序保存在 URL，返回保留上下文。抽屉用于快速查看，完整详情保留独立路由。只有短操作使用对话框，不把复杂配置塞进弹窗。

## M1 优先五个页面

1. 运行总览：紧凑状态条 + 任务趋势 + 需要处理的异常列表；“部分来源待授权”不渲染为全系统停机。
2. 规则编辑：目标、范围、关键词、时间/频率；高级配置折叠。新建默认草稿。
3. 信息列表及详情：列表中标题、来源、时间、关联客户、核实状态；详情并列展示原文摘要和分析，分析缺失显示待处理。
4. 账号管理及异常详情：账号状态、最近成功、失效原因；重新授权进入受控登录流程，验证后恢复相关任务。
5. 大屏：顶部为多组趋势图，中间左侧来源终端、右侧信息库，底部分配与接收表；统一石墨灰。

## 关键流程

### 首次使用

系统没有任何集成时显示“尚未配置搜索服务”，允许编辑规则，不用全屏报错。添加搜索服务 → 测试连接 → 新建关键词规则 → 试搜预览 → 启用。CRM、AI 和通知未配置均不阻止启用搜索。没有可执行来源的规则可保存，但启用时说明缺少能力。

### 规则配置

保存草稿不触发任务；试搜创建一次有数量/费用上限的异步任务，显示进度，结果不默认推送。测试失败保留所有输入。启用后展示下次执行时间，修改配置产生版本；暂停只影响当前规则。避免在首个输入前或输入中途显示错误，失焦/提交后给出字段级说明，提交失败定位到错误处。

### 账号失效与恢复

来源行显示“等待重新授权”，并显示“其他来源正常运行”。点重新授权 → 扫码或人工登录 → 校验有效性 → 显示恢复范围 → 限速重新入队。扫码过期可刷新；授权失败不误显示成功；关闭页面不影响其他任务。原型只能模拟并标注，不创建真实凭证。

### 信息处理

全网信息可没有企业、金额或客户关联。人工可记录“待核实、跟进中、已归档”等工作状态，不设置强制三级评分。相似内容合并展示来源，新事件进展保留时间线。用户确认客户归属后留存审计；AI 推断与原文分区。

### 通知

未配置渠道显示“未启用通知”，不阻止入库。区分排队、发送中、发送成功、失败、结果未知、人员确认；渠道未提供已读回执时不显示已读。手工重发说明可能重复的范围，操作结果有反馈。

### 大屏

事件驱动动作；无任务时显示待命并保持可选巡游，不增长数量。断线时显示最后更新时间和重连状态。不提供暂停动画或演示场景按钮，遵循系统减少动态效果设置。原型固定显示“演示数据”，真实环境显示“实时/连接中/数据已过期”。对外展示默认隐藏客户姓名、具体服务内容、敏感原文和接收人实名。

## 状态矩阵

| 状态 | 界面行为 | 可执行操作 |
|---|---|---|
| 加载 | 保留布局，不闪烁清空已有信息 | 取消或等待 |
| 空数据 | 说明未配置、尚未发现或筛选无结果 | 对应的配置/清除筛选入口 |
| 部分失败 | 正常内容仍可操作，失败定位到来源或任务 | 查看原因、重试、重新授权 |
| 服务不可用 | 显示等待或缓存快照与时间 | 更换服务、查看配置 |
| 无权限 | 说明访问受限，不泄漏记录细节 | 返回可用页面 |
| 保存失败 | 保留输入，展示字段或服务错误 | 修正、重试 |

## 原型验收

可用键盘走通新建规则、查看详情、账号恢复；表单标签和焦点正常；表格窄屏可访问；实时新增不抢走焦点；减少动态效果有效；对外大屏不含内部数据；所有按钮有真实原型反馈，没有伪装为已完成的真实采集操作。

## 实现基线 0.1

当前管理入口 /rules、/tasks、/information；大屏 /display。账号、客户和通知页面尚未开放，避免出现无效果的按钮。当前支持令牌认证，表单用原生约束校验并在提交时显示错误。大屏的真实/演示数据范围明确分离，独立展示令牌只能读取脱敏结果。

## 最新大屏覆盖规则：四图与信息片

用户确认的原始石墨灰图表样式优先于前述日历/散点方案。顶部四格为采集趋势、来源分类、任务积压、中国地图；地图不带解释侧栏。下方来源终端占约三分之一，信息表占三分之二。信息片为原句彩色标签，蜘蛛从对应原句位置搬运到表格，来源保留同色高亮；一条信息可包含多个片段，不合成摘要。生产界面不显示测试入口或动画暂停按钮，尊重系统减少动态效果。
