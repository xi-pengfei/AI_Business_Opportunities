## 技术验收，不等同业务效果评价

- 关闭 CRM、AI、通知，关键词搜索仍成功入库。
- 一个账号失效，其他账号与来源继续；登录恢复只恢复相关任务。
- Worker 中途退出，租约过期后可重新执行，不重复生成信息。
- Redis 重启或任务丢失，可从数据库未完成记录重建。
- 数据库不可用时不确认成功，恢复后可继续；备份能实际恢复。
- 外部供应商全不可用时保留任务并显示等待，不虚增计数。
- 通知超时结果未知时单独记录；渠道不支持幂等时不宣称严格一次送达。
- SSE 断线重连可补取；事件过期后用快照恢复；前端离线显示最后更新时间。
- 24 小时预发布运行观察资源增长、队列积压、任务推进和错误；这不构成绝对可用性承诺。

## 外部依赖的提供时点

- M1 无需账号、客户资料或付费服务。
- M3 需要一组真实关键词与一个搜索服务凭证；凭证从安全配置录入。
- M5 需要测试 IM 渠道；M6 需要脱敏样本和只读接口说明。
- M7 需要各类代表性 URL、可用授权方式及账户。
- 发布前确定服务器、域名、访问权限、备份位置；远程 Git 需确定平台及所属账号或组织。
