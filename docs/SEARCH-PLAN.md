# 搜索发现与独立分页（2026-11-15）

现场诊断发现：旧调度按总批数统一把关键词推向第 17/18 页；DuckDuckGo CAPTCHA 被当成无结果；Bing 在 SearXNG 中实际未启用却计入成功来源。相同查询回到第一页可返回结果，Brave 入口也已实际返回结果。这不是全国商机枯竭。

## 已部署规则

- 每个规则版本、关键词表达、搜索引擎组合拥有持久化 SearchCursor。页码与空结果计数独立，重启保留。
- 保留用户原始关键词，同时按 ERP、MES、信息化、数字化等主题拆分为采购公告、升级改造、建设需求等短查询；不再强制把地域词附到每个查询。
- 默认使用 SearXNG 已启用的 DuckDuckGo / Brave。每次检查 /config，只调用实际启用的入口，不回退到付费服务。
- 连续两页确实为空，或相邻两页返回完全相同 URL 集合，则结束这次深翻，300 秒后重新排队检查该查询的第一页。即使深页仍有结果，距上次第一页超过 300 秒时，下次选中该查询也先检查第一页。实际执行时间受其他查询和网络耗时影响。
- CAPTCHA / HTTP 403、429 / 明确封锁标记视为受限，入口整体冷却 300 秒。其他入口异常冷却 120 秒。其他可用入口继续，不用换关键词向受限入口连续重试。连续任务使用游标恢复，不用任务内重复重试堵住其他查询。
- 有结果同时有入口错误时标记 partial_results，保留可用结果；无结果且有入口错误不宣称正常空结果。
- 清洗仍执行近 30 天、来源日期核实、相同网址/正文去重，以及正常商机筛选。仅在采购付款条款出现 ERP 发票字样，不视为 ERP 软件需求。

## 大屏口径

显示当前查询、实际选择的入口、独立页码、空结果或受限状态、最后搜到结果时间、最后新增活跃商机时间。返回结果不等于新商机入库；搜索索引不是实时新闻流，发布到被索引有延迟。

## 边界

当前仍主要读取搜索摘要，缺失日期与主体证据会漏掉潜在需求；下一阶段需安全的原文读取、站点专项连接和日期补证。关键词组合和入口数量也不等于全网覆盖。新增候选需要人工核实，不承诺不停翻页就一定持续得到新商机。
